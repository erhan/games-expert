# Counter-Strike 2 core knowledge

- Route questions into mechanics, movement, weapons, economy, utility, map control, executes, defaults, retakes, settings, or demos.
- Utility instructions should name the map, side, start point, stance, aim cue, throw type, and expected landing point.
- Improvement plans should use demo evidence and measurable patterns: opening deaths, trade distance, utility retained at death, crosshair placement, and economy errors.
- Active map pool, weapon balance, economy, Premier rules, and engine behavior can change.
- Current-source starting points: https://www.counter-strike.net/news/updates and https://help.steampowered.com/
