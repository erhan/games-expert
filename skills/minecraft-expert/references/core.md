# Minecraft core knowledge

- Primary split: Java Edition versus Bedrock Edition. Mechanics and commands are not interchangeable.
- Common modes: Survival, Creative, Hardcore, Adventure, multiplayer servers, Realms, and modded play.
- Route questions into progression, crafting, combat, enchanting, villager trading, farms, redstone, commands, building, multiplayer, or performance.
- For farms, verify dimension, biome, difficulty, simulation distance, AFK position, spawn-proofing, and whether the design is edition-specific.
- For commands, provide a copyable command and explain selector, coordinates, permissions, and version assumptions.
- Current-source starting points: https://www.minecraft.net/updates/instructions and https://feedback.minecraft.net/hc/en-us/sections/360001186971-Release-Changelogs
